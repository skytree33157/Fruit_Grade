# Fresh Check: 과일·채소 신선도 판별 AI 프로젝트
 
사진 한 장으로 과일과 채소의 신선도를 분석하고, 어떤 형태가 신선한 형태인지 알려줍니다.

---

## 주요 기능

* **실시간 이미지 분석:** 카메라로 촬영하거나 업로드한 과일/채소 사진을 AI 모델이 분석합니다.
* **신선도 점수화:** 단순히 '신선함/부패함' 이분법을 넘어, 신선도를 백분율(%) 점수로 제공합니다.
* **신선도 정보**: 촬영한 과일/채소가 어떤 특징을 가져야 신선한 것인지 알려줍니다.

---

## 기술 스택

* **언어:** Python
* **Framework:** PyTorch
* **Computer Vision:** OpenCV
